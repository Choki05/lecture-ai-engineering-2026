# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：一般的な3レベルについての解説(初級・中級・上級)
- 用語集の正しい意味と比べて気づいたこと：講座の情報があれば、簡単に答えられることだった
- 表示できたトークン数（入力 / 出力）：[usage] input: 21, output: 456

## 宿題

- 取り組んだレベル：実装
- やったこと：-chatを付けて質問することでexitと送るまでは、それまでの会話履歴を保持しながらチャットを続けられるようにした
- 結果：-chatを付けて、連続でしか成り立たないような指示語を含めた質問をしても、前回の会話を引き継いで正しく回答するようになった
- 気づき・疑問：会話履歴の引継ぎはあくまでそれまでの履歴を再度LLMに送りなおすということであったので、通常のLLMでも会話履歴が長くなるとより多くのトークンを消費してしまう理由がよくわかりました。
